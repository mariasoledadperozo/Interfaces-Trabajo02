<h1>Rockstar Landing Clone</h1>
<hr/>
Landing page responsiva de Rockstar recreada con fines educativos.  
Desplegada en **[Vercel](interfaces-trabajo02.vercel.app)** para que puedas verla online.

<h2>Tecnologías usadas</h2>
<hr/>
- HTML5
- CSS3
- JavaScript (vanilla)
- Bootstrap 5
<h2>Demo</h2>
<hr/>
Accede a la landing online: [interfaces-trabajo02.vercel.app](interfaces-trabajo02.vercel.app)

<h2>Instalacion local</h2>
<hr/>
1. Clonar el repositorio:
   git clone https://github.com/tu-usuario/rockstar-landing-clone.git
2. abrir index.html en el navegador

<h2>Funcionalidades</h2>
<hr/>
<ul>
  <li>Diseño responsivo (adaptable a móviles, tablets y escritorio)</li>
  <li>Navbar fijo con enlaces ficticios</li>
  <li>Secciones con imágenes y contenido estático</li>
  <li>Footer con links de redes sociales y contacto</li>
</ul>
